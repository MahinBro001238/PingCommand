## **Brief Overview**
Ping Command adds a `/ping` command to your server that shows a player's ping. It is fully customizable through the config.

## **Commands**
- `/ping` — View your own ping
- `/ping <player>` — View another player's ping
- `/pingreload` — Reload the plugin's config

## **Permissions**
| Permission | Description | Who has it by default |
|---|---|---|
| `pingcommand.ping` | Allows use of the /ping command | Everyone |
| `pingcommand.other` | Allows viewing the ping of other players | No one |
| `pingcommand.reload` | Allows use of /pingreload | Operators only |

## **Minecraft Version And Server Software**
This plugin was built for all Minecraft versions between 26.3 and 1.16.5 running on Bukkit, Spigot, Paper and Purpur. It may or may not work on other server softwares or versions. It should work on forks of Paper such as Purpur and Pufferfish, though it has not been tested on them.
